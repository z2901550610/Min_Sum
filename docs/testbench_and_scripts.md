# Testbench And Script Map

## Make Targets

- `make test-unit` runs focused module benches for codec, RAM, shift, CNU, and VNU blocks.
- `make test-integration` runs `tb_decoder_top` with the toy parameter set and golden-generated vectors.
- `make test-bike-random BIKE_RANDOM_TRIALS=100` generates 100 independent BIKE-shaped decoder cases with consecutive seeds and prints a summary.
- `make test-bike-random BIKE_RANDOM_TRIALS=100 BIKE_RANDOM_RAM_LANE_DEPTH=40 BIKE_RANDOM_SUPPORT_MODE=random` runs random cases with a fixed RAM-I main depth.
- `make test-bike-overflow-cases` runs four deterministic RAM-I partition cases: below main depth, exactly main depth, one entry overflow, and all entries in one lane.
- `make test-bike-l1-cycle` runs the BIKE-L1-shaped cycle bench.

## Testbenches

- `tb/tb_msg_codec.sv` checks sign-magnitude and two's-complement message conversion.
- `tb/tb_ram_i.sv` checks the RAM-I main memory functional port, count write, and reset behavior.
- `tb/tb_ram_blocks.sv` checks RAM-C, RAM-M, RAM-S, and RAM-T focused behavior.
- `tb/tb_h_shift.sv` checks row-group target and shifted local row computation.
- `tb/tb_cnu_a.sv` and `tb/tb_cnu_b.sv` check the check-node update blocks.
- `tb/tb_vnu.sv` checks variable-node accumulation and extrinsic message generation.
- `tb/tb_decoder_top.sv` checks the toy top-level schedule, RAM-I shift commits, c2v/v2c overlap, drain state, and final golden vector result.
- `tb/tb_bike_l1_cycle.sv` measures a BIKE-L1-shaped single-iteration cycle count.
- `tb/generated/**/tb_bike_decoder_random.sv` is generated by `scripts/run_bike_random.py` for one random or shaped decoder case. It checks RAM-I main/overflow partitioning, count bounds during simulation, success flag consistency, residual weight, output weight, and exact match against the generated target error.

## Scripts

- `scripts/run_bike_random.py` owns generated BIKE-shaped decoder simulations. It emits a case-local `bike_pkg.sv`, RAM-I hex files, and a matching generated testbench, then compiles and runs each case. Use `--trials` for repeated random testing, `--ram-lane-depth` for fixed main-depth testing, and `--support-mode` for deterministic group distributions.
- `scripts/ram_i_hex.py` owns shared RAM-I first-column table construction and hex emission.
- `scripts/gen_qc_first_columns.py` parses `rtl/bike_pkg.sv` and emits the checked-in RAM-I hex files under `rtl/generated/`.
- `scripts/verilator_quiet.py` wraps Verilator, preserving full logs while keeping terminal output compact.
- `scripts/run_quiet.py` wraps simulation runs and stores runtime logs.
- `scripts/vivado_synth.tcl` is the Vivado synthesis entry script.

## Generated Data

- `rtl/generated/ram_i*_entries_*.hex` and `rtl/generated/ram_i*_counts_*.hex` are deterministic RAM-I initialization files generated from `rtl/bike_pkg.sv`.
- `tb/generated/bike_random/**` contains generated random decoder cases.
- `tb/generated/bike_overflow_cases/**` contains generated deterministic RAM-I partition cases.
